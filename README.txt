NEXPLAY — WEB INICIAL LISTA PARA PUBLICAR

Contenido:
- index.html: portada y estructura de la web.
- styles.css: diseño adaptable a móvil y ordenador.
- games.js: catálogo y tres minijuegos originales jugables.
- robots.txt y sitemap.xml: archivos básicos para buscadores.

IMPORTANTE:
Esta es una base web independiente. No contiene todavía los 25 juegos de la versión anterior porque el ZIP original no estaba adjunto en esta conversación. Para publicar los 28 juegos, integra los juegos originales y actualiza el catálogo antes del lanzamiento.

PRUEBA LOCAL:
1. Descomprime el ZIP.
2. Abre index.html en Chrome, Edge o Firefox.
3. Prueba Cazador de estrellas, Camino de colores y Burbuja veloz, tanto con ratón/teclado como con controles táctiles.

PUBLICAR GRATIS CON GITHUB PAGES:
1. Un adulto crea/inicia sesión en https://github.com/ y crea un repositorio público llamado nexplay.
2. Sube el contenido de esta carpeta directamente a la raíz del repositorio (index.html debe quedar en la raíz).
3. Abre Settings > Pages.
4. En Build and deployment, elige Deploy from a branch; Branch: main; Folder: /(root); pulsa Save.
5. GitHub mostrará una dirección con formato https://USUARIO.github.io/nexplay/.

DOMINIO .COM:
- https://www.nexplay.com es solo el dominio objetivo, no está comprado ni se ha comprobado su disponibilidad.
- Un adulto debe comprobar y registrar el dominio con un registrador. Después, en GitHub Pages > Custom domain, introducir www.nexplay.com y configurar los DNS indicados por GitHub/el registrador.
- No se ha comprado dominio, creado cuenta, subido archivos ni publicado la web desde este paquete.

GOOGLE:
Una vez publicada y accesible, añadir la URL a https://search.google.com/search-console/ y completar la verificación de propiedad. Enviar sitemap.xml y solicitar indexación de la página. La indexación no es inmediata ni está garantizada.

PRIVACIDAD Y DEPENDENCIAS:
No hay anuncios, analítica, cuentas, formularios ni recogida de datos personales. El CSS importa fuentes de Google Fonts; si prefieres cero peticiones a terceros, elimina la línea @import de styles.css y se usarán fuentes de sistema.
